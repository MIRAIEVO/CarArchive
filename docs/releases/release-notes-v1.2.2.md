# CarArchive 1.2.2

共同作者为 MIRAIEVO、Codex（OpenAI）、GitHub Copilot（Microsoft）。

## 导入与性能

- 修复清空分组后再次导入时缓存目录缺失，缩略图全部失败且误报原图丢失的问题。
- 缩略图优先读取 Windows 缓存或比例一致的内嵌图，缺失时小图解码，继续保持完整图片比例。
- 本机同一批 64 张 HEIC，原实现 23.78 秒，升级后 2.00 秒，均零失败。速度受格式、系统缓存与硬件影响。
- 批量导入的时间间隔窗口新增导入视频开关，并记住选择。

## 交互

- 界面、快捷键提示和任务状态统一使用“Gemini识别”。
- 多图上传开关移到识别模式右侧，所有分组共用并跨重启记忆。悬停可查看行为说明。
- 识别中仍可复制框选图片。粘贴 JSON 后自动解析和预览，只需点击确认应用。
- 多选分组自动显示悬浮合并按钮。两个右键菜单按本轮要求重排、改名，并使用主题适配的 SVG 路径图标。
- 模糊补全允许点击其他输入框直接激活。设置改为固定内容尺寸的主页及四个子页。
- 设置新增清除记住命名数据、清除崩溃报告入口。内置命名指南继续保留。
- 自动生成的名称剔除冒号和正斜杠，原始识别字段保持完整。

## 数据升级

新便携包的首次导入仅复制 API Key、各类设置、命名学习和目标分类目录配置，分组、媒体缓存与文件操作历史从空白开始。旧版 Data 保留。需要继续处理旧分组时，请在旧版本完成处理后再切换。

## 崩溃排查与验证

指定 1.2.1 报告及 Windows WER 显示 Microsoft.UI.Xaml.dll 的 c0000005 原生访问异常，发生前有查询完成、合并、拆组和框选。原报告没有托管堆栈，现有记录无法证明唯一根因。本版将右键结构编辑延后至菜单关闭、避免重复绑定同一图片列表、将任务完成刷新排入 UI 队列，并关闭分组容器增删动画，以降低这条路径的重入风险。

核心回归 178/178、图像测试与 MP4 原图保全、隔离原生窗口 18 项检查通过，覆盖二次导入、JSON 自动解析、浮动合并、全局上传记忆和固定设置导航。本轮不调用真实 Gemini API。发布包不含用户照片、数据库、凭据或聊天原文。
