# CarArchive 1.2.3

共同作者为 MIRAIEVO、Codex（OpenAI）、GitHub Copilot（Microsoft）。本版在体验包基础上完善并正式发布。

- 单图／多图开关显示当前文字，两个右键菜单的撤回、重做操作各自成块。
- 设置实时保存，底部统一为确定；首页单独列出确认弹窗，可逐项设置不再显示及恢复。有效模型 ID 和数字在输入时保存，无效或空白输入保留上次有效值。
- 合并按钮精简为合并，位于最后选中行的右侧，随列表滚动，离开可视区域即收起。
- 合并保留信息的优先级为已有字段、已完成识别、列表排序。API 和网页 JSON 回填均作为识别来源；手动名称和归档目标跟随被保留组。
- 点击确认并移动直接执行归档。回到已归档组后，同一个按钮以不同底纹显示撤回移动，撤回该组的移动记录。
- 识别期间可以复制成独立且待识别的新组。Gemini识别按钮在任务期间切换为取消识别。
- 操作栏增加完整高度和圆角，收起联网验证状态提示，继续提供识别字段和 API 内容。
- JSON 窗口靠近右上角粘贴按钮向左下展开，使用固定尺寸、自动解析和简洁名称预览。新增粘贴即确定开关并记忆状态，开启后有效 JSON 自动应用并关闭，解析失败保持打开。

解压 ZIP 后运行根目录 CarArchive.exe。首次启动可从旧版本 Data 导入 API、设置、命名学习及目标目录配置。旧分组继续在原版本处理。

本轮使用隔离数据和合成图片验证交互及文件移动／撤回，不调用真实 Gemini API。具体结果见项目交接记录。

## 正式版补充

- Gemini识别与取消识别固定尺寸和位置；取消识别与撤回移动采用一致的偏红底色及悬停状态。合并按钮右侧留距增加，滚动到上下边缘时吸附。
- JSON弹出框明确设置内容宽度、外层宽度与内边距，禁止横向滚动；全局控件、卡片、菜单和对话框建立圆角层次。
- 缩略图使用弱引用缓存复用BitmapImage，高清预览和状态更新不再重复通知相同缩略图地址。
- 识别成功后始终重新生成名称和品牌目录，清除旧手动目标标记，按用户选择不保留旧自动命名回退值。
- 本地指南快照覆盖144品牌、2013分类，完成2069组输入名称推演；20个大品牌目录已追加补充要求，原手写内容保留并有备份。指南随软件发布，运行时不依赖原分类目录，指南及命名记录不发送给API。
- 通用提示词要求已识别车辆填写代次，单代也填1st，并核对本代改款总数后选择Facelift或带序数的改款阶段。底盘后面的改款序数得到完整保留。
- 随包提供命名输入推演、命名差异、品牌资料索引和改款核对表。品牌检索索引覆盖144个品牌、138个有检索结果；检索命中不等于具体车型事实已核实。部分厂家页面不可读取，车型的完整改款总次数仍需识别时查证；未确认项目在核对表中保留为空并标明待核对。

官方改款资料示例采用Audi Q7二代升级历史和Lexus CT车型回顾。
