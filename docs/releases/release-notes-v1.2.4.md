# CarArchive 1.2.4

- **识别按钮更紧凑**：按“图标 + Gemini识别”测量固定宽度，取消时尺寸和位置不变，内容整体居中。
- **红色操作更清楚**：取消识别与撤回移动共用更深的红色，悬停时减淡；支持浅色、深色及高对比度主题。
- **轻快动效**：增加短促的按压反馈、分组信息与设置页面切换、合并按钮出现动画；遵循 Windows 动画设置，不重复播放高清预览升级动画。

## 升级

解压至新目录，启动根目录 CarArchive.exe。可从旧版本导入设置与命名学习记录；原版本 Data、原照片及已归档目录不作修改。便携包不含照片、数据库或 API Key。

## 验证

发布前执行构建、隔离数据的真实窗口检查及便携包解压启动检查。本版不执行真实 Gemini API 调用。
