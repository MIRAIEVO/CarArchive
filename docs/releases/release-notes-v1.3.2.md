# CarArchive 1.3.2

- 「生产年份」填写已识别的改款阶段（含中改前）的生产年份；未知留空。旧记录仍保留原值。「车身形式」与「官方完整营销名称」去掉括号附注。
- 文件按内容比较，不受文件名影响。发现重复时可仍移动、回收待移动文件或取消本组。非重复文件直接移动，重名自动加序号。
- 右下角新增「打开品牌目录」，可打开当前已存在的品牌目录，包括已归档分组。

完整解压后运行 CarArchive.exe，保留 Program、Data、Documentation 目录。发布包不含用户照片、数据库或 API Key。
