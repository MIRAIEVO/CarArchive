# CarArchive 1.4 体验版

解压完整便携包后运行根目录的 `CarArchive.exe`。从工具箱打开「重复文件检查」，也可直接运行 `Tools/DuplicateChecker/DuplicateChecker.exe`。独立 ZIP 解压后可单独使用。

查重可用于从待处理照片和视频中找出尚未进入分类目录的文件。比较目录只读。检查完成后可以预览、确认移动、载入操作记录及还原。设置首页更新了导航布局和 SVG 图标。

查重窗口采用矢量图标、进度条和分类计数。多选组内照片时，快捷按钮出现在最后选中的缩略图上。自动命名会补齐缺失的车系，沿用已有车型命名特例。

归档发现重复内容时，可在工作区提示条决定如何处理，同时切换到其他分组。复制给网页的核验提示词允许凭足以识别的独有官方外观通过。命名指南已按现有本地分类和补充要求重扫。
