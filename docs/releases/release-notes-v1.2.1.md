# CarArchive 1.2.1

共同作者：**MIRAIEVO、Codex（OpenAI）、GitHub Copilot（Microsoft）**。

- EXIF 时间与缩略图分离：8 个元数据任务、2 个图像解码任务；直接解析 HEIF 的 iinf／iloc／idat EXIF，以及 JPEG、TIFF／DNG、PNG、WebP，不为读时间解码整图。元数据就绪后即可完成时间分组。
- 鼠标锚点缩放，原图读取避免每次滚轮重复解码；框选上传保持原坐标。
- 「深入查证」改名「复制框选图片」，预热编码与剪贴板相关工厂，复制复用完整无损预览；API 图片处理不降低分辨率。提示词明确要求可回填的十字段 JSON。
- 新增 JSON 粘贴弹窗：解析预览、字段与本地命名同步，忽略 Key 和网页“验证通过”声明，不触发 API 或自动归档。
- 检索只保留 Gemini（默认）与 Gemini + Google Search grounded，删除图片检索／Lens 选项和付费能力探测入口。高级设置改为读取账号模型清单，不发送照片、不生成内容。
- 模型 ID 改为可编辑下拉，默认 3.8 Flash，包含官方 Gemini 4 Hydrogen、Argon、Carbon 等。账号权限／额度仍由接口决定。[官方模型清单](https://aistudio.google.com/docs/models)、[Hydrogen 接口说明](https://aistudio.google.com/docs/whats-new-gemini-4-hydrogen)。
- 手动记住名称日志保存原始、确认字段和自动／最终名称，最多 1000 条，可导出带中文表头的 CSV；崩溃报告启动及写入时均限制最近 10 条。
