# CarArchive 1.1.5 — 交互、快捷键与照片管理

本版基于 1.1.4，汇总 2026 年 11 月 13 日至 16 日的协作与改进。

## 下载与升级

下载 Windows x64 便携 ZIP，完整解压后运行根目录 **CarArchive.exe**，保留 Program、Data、Documentation。升级前关闭旧版；首次启动可导入旧 Data。旧版本、备份和原照片不自动删除，发布包不含用户照片、数据库或 Key。

## 主要变化

- 车型／品牌共享左侧原生模糊建议，空间不足自动回退，修复定位、动画、圆角与输入焦点问题。
- 新增可配置的识别、查证、切组、归档、移除及回收快捷键；保护输入框编辑和建议列表导航。
- 按操作记忆“下次不再显示”，支持恢复全部提示；跳过弹窗仍执行全部文件安全检查。
- 复制组立即生成独立、校验后的原图副本；待处理源照片可单独移入回收站，记录移除默认保留文件，已归档照片不回收。
- Codex 与 Copilot 已完成历史交接并按文件协作；整理项目说明、版本文档和开发工具。
- 识别 Token 优化提供兼容回退；具体启用策略和前后对照结果以最终验证记录为准。

默认快捷键：Ctrl+R 识别；Ctrl+Shift+R 查证；Alt+←／→ 切组；Ctrl+Enter 归档；列表中 Delete 移除记录；Ctrl+Shift+Delete 回收待处理源照片；输入框外 Ctrl+Z 撤销最近归档。

## 本版边界

分类目录已重新连接，本轮重新扫描 **131 个品牌、1920 个分类目录、8 份补充要求**，生成完整规则核对表与覆盖清单。品牌、车系及具体车型规则随程序发布，补充要求优先于历史格式，原目录离线时仍可命名；目录补全只列出现存分类。支持 Audi、BMW、Ferrari、Mercedes-Benz／AMG／Maybach、Porsche、Rolls-Royce 的明确命名要求，未知字段不猜测，既有归档目录不自动改名。

真实识别对照最多 40 次调用，由主协调统一计数。不以有限样本承诺所有图片零退化，不承诺固定 Token 节省、准确率或内部搜索次数。
