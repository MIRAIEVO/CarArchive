# CarArchive v1.2

共同作者：**MIRAIEVO、Codex（OpenAI）、GitHub Copilot（Microsoft）**。

本版包含从公开版 1.1.4 以来的交互、照片管理和命名升级；原计划的 1.1.5 未单独发布。

## 识别与工作效率

- 每组独立保存强度和单张／多张上传设置，默认精简字段。单张取当前预览或其框选；多张只取所有未排除的框选图，没有框选时回退当前整图，所有模式一致。
- 查询中可以创建独立副本、拆出未上传照片；结果只回写原组。合并保留排序靠前组的识别与命名。
- 深入查证改为复制无位置 EXIF 的派生图片文件和验证提示词，不再调用手动查证 API。网页只接收图片时，可再点击复制提示词分开粘贴。
- 归档队列不阻塞其他组；手动切组后完成归档不抢回选择。

## 照片与交互

- 原生车型／品牌模糊建议弹层、可配置快捷键、分操作确认偏好、独立原图副本和仅回收站删除。
- 原文件直接索引，缩略图优先；图片滚轮缩放使用原图，裁剪坐标与上传图像不受缩放影响。
- DNG 接入 Windows RAW 解码；视频可播放／拖动，识别使用当前帧，归档仍为源视频。格式能否解码取决于系统对应解码器，失败不会修改原文件。
- 组与组内右键撤回／重做编辑，Ctrl+Z 撤回最近编辑或归档，输入框保留原生撤回。独立副本撤回备份存于 Data/undo。回收撤回从校验备份恢复源字节，回收站中的旧项仍保留。
- 撤销归档只清理本次实际创建、当时仍为空的目录；任何其他文件都会阻止目录清理。
- 清理已归档组是不可撤回的记录清理，并清除相应缓存／撤回内容；已归档文件不受影响。

## 随包命名指南

重新核对 131 个品牌、1920 个分类目录及 8 份补充要求，内置品牌／车系／车型规则与中文核对清单。不依赖分类根目录存在，不上传指南或历史命名。保留完整营销名、Body 不重复拼接、重音转写、德系四驱标识省略、Mercedes 车系前缀、BMW LCI、Ferrari 无括号、Porsche 911 的 .2 及 Audi／Rolls-Royce 例外。修复自动品牌目标错误匹配，用户主动选择的跨品牌目录仍明确保留。

## 升级与数据

完整解压，运行根目录 CarArchive.exe，保留 Program、Data、Documentation。新包 Data 为空，不包含照片、数据库、Key 或聊天原文。关闭旧版后在首次启动入口选择导入旧 Data；旧 Data 不删除、不覆盖。源照片与归档路径保持原值；API Key 仍绑定当前 Windows 用户。

删除源照片前创建校验撤回备份，需要额外磁盘空间；无法使用回收站时停止，不永久删除。撤回／重做遇到源文件冲突会停止，不覆盖文件。历史关联操作需要按依赖先后撤回。
