# CarArchive 1.3.3

- 「设置 → 外观」可选择跟随系统、浅色或深色，即时生效并记忆。
- 归档根目录和相对目标路径集中展示，两个目录按钮并排，路径和规则均可悬停查看完整内容。
- 加固切组、缩放和框选期间的预览交接。崩溃报告增加检查点时间、最后 UI 响应、进程内存、异常类型和 HRESULT；从便携启动器运行时，下一次启动可补记已捕获的异常退出码。日志仍只保存最近 10 份报告。
- 重扫现有命名目录与补充文件，更新 175 个品牌、2,708 个目录的随包指南。修正编号改款及 Audi 衍生车型的代次匹配。167 项历史命名差异保留于复核表，既有目录不改名。

完整解压后运行根目录 CarArchive.exe。发布包不含用户照片、数据库、密钥或崩溃报告。
