# CarArchive 1.3.1 使用说明

完整解压后运行根目录 `CarArchive.exe`，保留 `Program／Data／Documentation`。首次启动选择导入旧版 Data 或创建空工作区，迁移前关闭旧版；旧 Data 不删除、不覆盖。新包不含照片、数据库或 Key。

## 导入和浏览

支持 JPG、PNG、WebP、HEIC／HEIF、DNG，以及常见视频格式（依赖 Windows 对应解码器）。批量导入仅索引文件夹顶层原文件，不复制原图。拍摄时间采用独立的 8 个元数据工作任务，优先直接读取 JPEG／TIFF／DNG／PNG／WebP／HEIF 的 EXIF；缩略图另用两个后台解码任务。未知时间仍按文件名自然排序，已编辑的组不被重新分组。

主预览滚轮以鼠标位置为缩放锚点，原图按需读取；框选与图像一起缩放，上传裁剪坐标不改变。小图同高密排、保持完整比例。视频可播放和拖动，识别取当前停留帧，归档仍移动源视频。

## 识别、复制和网页 JSON

在「设置 → 识别与费用」选 **Gemini、OpenAI、Claude 或 DeepSeek**，填写该厂商的 API Key，再选择或输入支持图片的模型 ID。各家独立记忆模型、联网开关及补充提示词；Key 由 Windows 当前用户加密保存。默认沿用 Gemini 及旧版设置，新厂商默认关闭搜索。DeepSeek 图片识别使用 `deepseek-flash`。

「模型清单与提示设置」可读取账号模型列表，不上传照片或生成内容；列表不保证模型支持图片、搜索或具备调用额度。补充提示词接受中英文，程序会要求 API 返回统一的车型 JSON。识别只向选定厂商发送所选图片和提示词；名称与目录仍在本机生成。

在左上角的识别强度弹窗中切换联网，并选择 Minimal、Low、Medium、High、Xhigh、Max 或 Ultra。所有档位仅返回车型字段。高档最多发出三次生成请求，搜索次数和生成轮次分开显示。在「设置 → 识别与费用」修改新分组默认档位和当前厂商的联网状态；已有分组的档位不变。

识别强度和联网按组保存；多选后修改会批量应用到可编辑组。未单独设置联网的组使用当前厂商的默认值。全新工作区默认 Gemini 3.8 Flash、Minimal、不联网。单图／多图仍跨分组使用；多图上传全部已框选且未排除的图片，无框选时回退当前整图。

**复制框选图片**（原「深入查证」）复制框选派生图片文件与验证提示词，不调用 API；没有框选时使用当前图。图片准备复用完整比例缓存预览并提前预热编码器，原文件不修改。粘贴到 Gemini 网页后，若只粘贴了图片，可再点「复制验证提示词」单独粘贴文字。提示词要求最后返回包含 Brand、Series、Variant、Body、OfficialName、Generation、Code、Phase、Package、ProductionYears 的 JSON。

在右侧点击 **粘贴 JSON**，粘贴网页回复，点击「解析并预览名称」核对后应用。支持代码围栏、说明文字和 Identity 包装；Key 等计算字段忽略。此操作仅导入车型字段并通过本地指南生成名称，不会把网页声称的“通过”当作接口查证证据，也不会自动归档。

## 命名与记录

最终名称使用完整营销型号，Body 只展示；去品牌、去指定德系四驱标识、转写特殊拉丁字母。代次／代号／年代、BMW LCI、Ferrari、Mercedes、Porsche 911 .2、Audi 与 Rolls-Royce 等规则由内置本地指南执行，不发送至 API。目录建议只来自实际存在的分类，显示「车型 / 品牌」，允许自由命名。

成功手动点击「记住名称」时，额外记录原始识别／网页字段、当前确认字段、实际自动名称与最终手动名称。日志从本版开始，最多最近 **1000 条**，不从旧记录猜测补录；尚未自动生成过的名称为空。到「设置 → 命名学习」导出 CSV。CSV 包含原始与确认字段，不含照片、Key 或照片路径。

崩溃日志只保留最近行为和异常，干净退出不保留行为记录；崩溃报告最多 **10 条**，位于 Data/crashes。

## 编辑、归档和快捷键

组与组内右键提供拆分／合并／独立副本、移除记录、回收源照片及撤回／重做。已归档照片不能回收；清理已归档记录会不可撤回地清理关联缓存和撤回内容，不删除归档文件。归档与其他组浏览编辑并行，不覆盖同名文件，跨盘复制校验后才删除源文件；撤销只清理本次创建且仍为空的目录。

| 操作 | 默认键 |
|---|---|
| 识别 | Ctrl+R |
| 复制框选图片 | Ctrl+Shift+R |
| 上／下一组 | Alt+←／Alt+→ |
| 确认并移动 | Ctrl+Enter |
| 列表移除记录 | Delete |
| 列表回收源照片 | Ctrl+Shift+Delete |
| 撤回／重做 | Ctrl+Z／Ctrl+Shift+Z（输入框保留编辑键） |

键位与按操作确认偏好可在设置恢复。数据、缓存、加密 Key、命名指南和日志均位于本版本 Data。Key 绑定当前 Windows 用户，换机需要重新输入。

## 操作调整

多图上传在识别模式右侧统一控制，悬停可查看说明。批量导入窗口可选择是否包含视频。粘贴 JSON 自动解析后点击确认。多选组显示合并按钮，组及照片右键菜单提供拆分、复制、撤回、重做和两种删除方式。设置首页进入各子页，命名页和维护页提供学习数据与崩溃报告清理。首次升级导入仅导入配置和命名数据，旧分组留在旧版本中。

## 1.2.3

设置一经修改即保存，底部点击确定关闭。确认弹窗在设置首页单独管理。AI识别在任务期间切换为取消识别；已归档组的移动按钮切换为撤回移动。多选分组在最后选中行右侧显示合并。粘贴 JSON 的固定窗口位于右上角附近，粘贴即确定开关会记忆选择，开启后有效内容自动应用。

正式版继续完善固定识别按钮、红色撤回状态、合并边缘吸附、JSON固定宽度及缩略图去闪烁。随包Documentation/Naming内提供完整命名指南、名称推演、差异与待核对表。识别成功后名称与品牌目录始终按新字段生成。

## 1.2.4

识别／取消使用紧凑固定宽度，图标与文字共同居中。取消和撤回移动使用更深的红色，悬停时减淡。按压与页面切换使用短促动效，并遵循系统动画设置。

## 稳定性续修

缩略预览显示后即可框选，无须等待高清图；高清升级保留框选。统一缩略图尺寸，取消识别悬停即时变红，预览纯色留白与图片共同淡入。修复照片右键命令，Shift多选合并按钮跟随最后点击行，合并采用短促快照堆叠动画。

最新测试包修复旧组主图残留、缩略图选中后尺寸变化及两个右键菜单的鼠标派发。合并时后续分组同步平滑上移。请完整解压新测试包后运行根目录启动器。
