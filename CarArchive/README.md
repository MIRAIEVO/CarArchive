# CarArchive 1.1.4 使用说明

## 开始使用

1. 完整解压便携包，运行根目录 `CarArchive.exe`，保留 `Program`、`Data`、`Documentation`；升级前先关闭旧版。
2. 首次启动导入旧版 Data、原 `%LOCALAPPDATA%\CarArchive`，或建立空工作区。已有数据不覆盖／合并；校验完成后才启用，旧目录不改动。
3. 「… → 设置 → 识别与费用」保存 Gemini API Key 和可访问模型。能力检查使用合成图片，会实际调用并可能计费；只保存 Key 不调用 API。
4. 选择归档根目录，导入一组或批量导入拍摄文件夹。批量导入可调整时间分组间隔，仅处理顶层照片。
5. 当前分组直接识别，无须确认分组。点击缩略图即设为代表图，多车同框时框选目标。
6. 核对字段与名称，检查固定右下的目标目录，点击「确认并移动」；每次归档仍需确认。

支持 JPG、PNG、WebP、HEIC／HEIF；HEIC 解码依赖本机 Windows 解码器。RAW、视频、跨设备同步和 Google Lens 反向图片搜索不在本版范围。

## 分组、预览与并行

导入先登记，后台读取元数据并生成小图；高清图按点击加载并预取相邻图片。图片解码并发两个任务，同原图共享缓存；已经操作的组不因后台元数据重排。

缩略图从完整原图解码并应用 EXIF 方向，不使用可能已裁切的系统／内嵌小图。原图可用时旧缓存按需升级。组内图片按完整比例横向密排，通常高120有效像素，低高度窗口为96，不裁切。底部切组按钮已移除，保留快捷键。

- 左栏右键：合并、复制、删除选中组、清理已归档组；删除仅移除记录，保留照片和目录。
- 照片右键：拆出、复制成新组、排除／恢复、删除引用；右键已选项目保留多选。
- 当前组与选中缩略图使用明显的强调蓝色底纹；组列表移除蓝色描边，切组自动滚动聚焦。
- 顶部识别模式与导入操作统一为紧凑高度，导入按钮文字与模式标签字号一致；预览区工具按钮居中对齐，应用图标使用新版车影图。
- 中央集中框选／识别操作，右上字段证据滚动，右下归档固定；窄窗口切换分组／照片／复核工作区。

默认两个 Gemini 任务并行，文件操作走独立串行队列。仅任务所属组暂停编辑，其他组照常使用。红点执行中、绿点任务完成、黄色失败／取消；完成不代表人工确认。取消只影响本组，后台结果不覆盖其他组或强行切组。中断查询不自动重发。

## 识别与特征查证

| 档位 | 行为 |
| --- | --- |
| 精简字段（默认） | 一张代表图，长边1280，十个身份字段；单请求，不追加核验 |
| 速度优先 | 最多三图，单次联网，完整字段与短证据／疑点 |
| 控制费用 | 一图、单请求、低预算和极简证据，不足时退回车系 |
| 准确优先 | 最多八图，联网识别并提取特征，再照片对照，必要时一次补证 |

**已有代表图框选时，所有带图请求只上传代表图实际裁剪像素，长边不超过1280，不上传其他完整视角。** 上传派生图不复制原始 EXIF／GPS；裁剪不改变原图和归档内容。

深入查证须已有待验证车型。第一次只带字段联网找具体辨识点；第二次带特征与图片对照，不启用搜索；仅在明确可补充的关键资料缺口下追加第三次。最多三次，不自动重试网络错误。

「API 返回内容」展示候选车型、特征、符合／矛盾／不可见、真实来源、修正及阶段用量。结论明确区分通过、不通过、证据不足、未完成；车系通过而配置未证实单独提示。没有实际搜索引用或关键可见证据，不显示通过。

修正不自动覆盖字段，点击「采用修正」后更新并本地命名；手动名称保留，可主动重新生成。查证与原识别分别保存，失败／取消保留已完成阶段；照片、框选或身份变动使旧结论失效。

用量只展示接口实际返回，未返回标为未知，不承诺固定费用、节省比例或内部搜索次数。精简模式生成预算包含思考；截断提示手动处理。检索默认自动，图片资料能力须通过模型检查，不自动更换模型或增加 Key；图片资料检索不是 Lens。

## 本地完整命名与学习

名称为完整营销名称／完整型号（去品牌，从车系开始，保留已确认车型、套件、特别版）加括号后缀。Body 仅展示，不重复拼接。默认 `完整型号 (3rd Facelift)`，不带gen／generation，中改前省略Pre-Facelift。缺失代次不拿代号猜测代次；未知版本退回完整车系。

括号依本地品牌／车系指南采用代次、代号或年代：Audi A4–A8及衍生车型用B／C／D常用代号，其他Audi用基础车系代次并规范RS3、A8L；BMW改款用LCI；Phantom用罗马数字，其他现代劳斯莱斯用现代代次、老车用有据年份。奔驰／宝马／奥迪默认省略4MATIC／xDrive／quattro，固有车名例外保留。Porsche 911适用的996／997／991／992等代号中改前用基础编号，中改后`.2`，不写`.1`或另加Facelift；字段冲突提示人工处理。

「命名学习」提供本地指南与CSV清单查看／重建。指南结合已有目录、确认字段与补充文件，按具体车系、型号和代次处理；冲突多数决后参考最近确认，仍无法区分则默认。现有目录不自动改名。指南、目录、补充文件与旧名称不发送API，不产生命名请求。

只有「记住名称」及归档确认产生学习样本。精确车型可直接记忆；至少两个不同配置的同车系一致才提炼车系规则，至少三个不同车系支持才提炼品牌规则。默认推广需确认，自动模式达门槛后应用，手动模式只接受显式记忆。规则可查看样本、预览、编辑、批准、停用、删除、导出；样本变更重算支持与冲突。规则不推广型号数字、配置等识别事实。

优先级：本次手动名称 → 明确补充要求 → 批准的范围规则 → 车型指南 → 兼容用词 → 默认格式。

## 现有目录模糊补全

名称和品牌输入框点击即弹出，无须改输入；输入为空时不显示建议，两类弹窗均始终在输入框左侧展开，首行顶端与输入框对齐，并以水平动画进入，位置稳定后才显示，避免闪变。仅显示归档根目录中的现存分类，每项只显示「车型 / 品牌」，品牌部分使用灰色文字，最多20项。车型建议按相关度从高到低排列，弹出列表最高约五行，更多结果可滚动查看；品牌建议沿用原排序。支持s63coupe连写／分词、词序、别名、同义词及有限拼写容错，不将不同型号数字误当拼写错误。

索引后台构建，输入只查内存，不联网。选择同步名称、品牌和路径，不改识别字段；继续编辑或切根目录解除旧路径关联。无匹配可自由输入；新输入和生成名称将重音／特殊拉丁字母转英文字母，现有目录按原样选择。

## 文件与数据安全

每次移动确认完整目标。原图不重编码；临时复制、SHA-256校验、发布目标后再次核对，再按共享引用删除源。不同内容重名加序号，不静默覆盖；同内容重复提示人工处理。

复制照片引用可分别框选不同车：各目标保存完整原图，尚有待归档引用时保留源，最后一组成功后才删源。排除／放弃引用不因编辑动作删除原图。单组撤销保留其他副本，原位置冲突则停止。「操作记录与恢复」记录逐项状态，中断须手动恢复，有未完成操作的组先恢复／撤销后再结构编辑。

数据库、缓存、指南、备份和崩溃报告位于该版根目录Data；根启动器和Program内EXE解析相同位置。目录不可写明确报错，不回退C盘。每版独立，同一工作区派生版本不可同时运行。首次导入一致性备份、校验及内部缓存路径更新，旧数据和原照片路径保持不变，不递归复制历史备份。

Key以DPAPI当前Windows用户加密，换机／换用户须重新输入。缓存清理保留缺原图时必要预览。崩溃报告仅含有限近期行为，不含照片、Key或输入全文，不自动上传；正常退出删除会话检查点。备份前关闭软件后复制整个Data。

快捷键：Ctrl+Enter归档确认；Alt+←／→切组；Ctrl+Z撤销最近归档。
