# CarArchive 1.2 使用说明

## 开始使用

1. 完整解压便携包，运行根目录 `CarArchive.exe`。保留 `Program`、`Data`、`Documentation`，升级前关闭旧版。
2. 首次启动可导入旧版 Data、原 `%LOCALAPPDATA%\CarArchive`，或建立空工作区。已有数据不覆盖／合并，校验完成后才启用新副本；旧目录不改动。
3. 在「… → 设置 → 识别与费用」保存 Gemini API Key 和可访问模型。仅保存 Key 不调用 API；能力检查会使用合成图实际调用并可能计费。
4. 选择归档根目录，导入一组或批量导入拍摄文件夹。批量导入按时间辅助分组，可调整间隔，仅处理文件夹顶层照片。
5. 当前分组可直接识别，无须确认分组。点击缩略图设为代表图；多车同框时框选目标。
6. 复核字段、名称、品牌和固定归档区的目标目录，再执行「确认命名并移动」。

支持 JPG、PNG、WebP、HEIC／HEIF；HEIC 解码依赖本机 Windows 解码器。RAW、视频、同步及 Google Lens 反向图片搜索不在本版范围。

## 浏览、分组与并行

导入先登记，后台读取元数据和生成完整比例小图；高清图按点击加载并预取相邻图片。解码默认两个任务，共享只读显示缓存；已编辑的组不因后台元数据被重新分组。

缩略图应用 EXIF 方向，以通常 120、短窗口 96 个有效像素同高横排，不裁切。旧裁切缓存在原图可用时按需更新。选中组自动滚动聚焦；窄窗口可切换分组、照片、复核工作区，归档按钮固定。

- 分组右键：合并、复制、移除组、回收待处理源照片、清理已归档记录。
- 图片右键：拆出、复制成新组、排除／恢复、移除图片引用、回收待处理源照片。
- 「移除」只删除工作区记录，保留文件；「删除并回收源照片」是独立的操作，不处理已归档副本。

默认两个识别任务并行，复制、归档、回收共用文件队列。仅任务所属组暂停编辑，其他组可照常操作。红点执行中、绿点任务完成、黄色失败／取消；完成不代表车型已通过人工复核。取消只影响本组，后台结果不会覆盖其他组或强制切组。

## 目录模糊建议

名称和品牌输入框有内容时，点击或输入即可打开现存目录建议。空输入不弹出；左侧空间不足时回退至右侧或下方。列表最多约五行，更多内容可滚动，按相关度从高到低显示，只呈现「车型 / 品牌」。

支持连写／分词、别名、同义词和有限拼写容错，避免把不同型号数字混为一谈。方向键选择、Enter 采用、Esc 关闭；输入刷新不重复播放打开动画。选择同步名称、品牌和路径，不修改识别字段；继续编辑或切换根目录会解除旧路径关联，无匹配可自由命名。

索引在本机后台建立，输入只查询内存，不联网。新输入和生成名称的重音／特殊拉丁字母转为英文字母；选择已有目录仍保留其实际拼写。

## 快捷键与确认提示

| 操作 | 默认快捷键 |
| --- | --- |
| 联网识别 | Ctrl+R |
| 深入查证 | Ctrl+Shift+R |
| 上一组／下一组 | Alt+←／Alt+→ |
| 确认命名并移动 | Ctrl+Enter |
| 移除选中组或图片，保留照片 | Delete，按当前列表焦点 |
| 删除并回收源照片 | Ctrl+Shift+Delete，按当前列表焦点 |
| 撤销最近归档 | Ctrl+Z，输入框外 |

设置中可改绑、清除和恢复默认，并检查冲突及系统保留键。输入框保留正常编辑快捷键，建议列表优先处理方向键、Enter、Esc；模态窗口打开时不执行后台命令。识别、归档和删除不因按住按键重复执行。

纯确认弹窗可勾选「下次不再显示」，包括回收照片；仅确认执行后记忆。设置可逐项恢复或恢复全部提示。跳过提示不跳过路径、文件、任务冲突和回收站能力检查；需要填写信息的窗口和错误提示不会自动代填或接受。规则审批选择以后自动采用时，会明确切换至自动学习。

## 独立副本、回收与归档

复制分组或所选图片时，在本版 Data 中后台创建完整原图副本，校验后分配独立资产与路径，保留文件名、字节和 EXIF。可共享只读显示缓存，但不同组不再共用可删除的源文件。复制期间显示进度，可取消；未完成的组不能归档。

升级会备份数据并隔离待处理组的旧共享引用；有中断文件操作或原图缺失时先处理具体问题。已完成的历史归档日志不重写。

回收逐文件记录结果，只移除已成功处理的引用；文件被占用、变化或无法回收时保留记录并显示原因。无法使用 Windows 回收站时停止，绝不自动改为永久删除。已归档组只能清理工作区记录。需要恢复回收的照片时，可打开 Windows 回收站。

归档不重编码原图。先临时复制并校验，再发布目标并核对，最后按操作计划处理源文件。不同内容重名加序号，不静默覆盖；同内容重复提示处理。撤销只作用于所选归档，路径冲突时停止。操作记录可查看逐项结果及恢复中断；未完成任务的组先恢复或撤销后再结构编辑。

## 识别、查证与用量

| 档位 | 行为 |
| --- | --- |
| 精简字段（默认） | 一张代表图，长边1280，十个身份字段；单请求，不追加核验 |
| 速度优先 | 最多三图，单次联网，完整字段与简短证据／疑点 |
| 控制费用 | 一图、单请求、低预算和极简证据，不足时退回车系 |
| 准确优先 | 最多八图，联网识别并提取特征，再照片对照，必要时一次补证 |

**代表图已有框选时，所有带图请求只上传该框选的实际像素，长边不超过1280，不上传其他完整视角。** 派生图移除原始 EXIF／GPS，不改变原图和归档内容。

深入查证需要当前待验证车型：先仅带字段联网找辨识点，再将特征与照片比对、不再次搜索，仅有具体可补充的关键资料缺口时追加第三次。最多三次，网络错误不自动重试。

「API 返回内容」显示通过、不通过、证据不足或未完成，以及逐项符合／矛盾／不可见、实际来源、修正建议和阶段用量。无真实搜索引用或关键可见证据不显示通过。修正由用户明确采用，更新字段后本地命名；手动名称保留。改变照片、框选或身份后，旧结论不再当作当前证据。

Token 优化不以降低照片分辨率、必要视角、思考档位或查证步骤为默认手段；先移除重复提示和无关阶段数据，并提供兼容策略回退。具体启用策略与实际前后对照结果见本版发布说明。用量缺失时显示未知，不承诺固定节省比例、单车费用、搜索次数或准确率；截断和异常响应不当作成功。

## 命名与本地学习

名称由随程序发布的本地指南生成：完整营销名称／完整型号去品牌后，加本地品牌／车系规则选定的代次、代号或年代。Body 仅显示，不重复拼接。未知字段不猜测，具体版本不足时退回完整车系；手动名称优先，现有目录不自动改名。

指南按品牌、车系及具体车型采用规则：Audi A4–A8 及衍生车型使用 B／C／D 代号，其他 Audi 按基础车系代次并规范 RS3、A8L；BMW 改款用 LCI；Ferrari 不加代次／代号括号；Mercedes-Benz、Mercedes-Maybach 用代号和完整车系前缀（如 S-Class S500、S-Class S580），Mercedes-AMG 独立归类并省略重复 AMG，AMG-Line 不当作 AMG 性能车型；Porsche 718、911、Cayman、Boxster 用代号，其他用代次，911 中改后 `.2`；Rolls-Royce 现代车型用现代代次、老车用有据年代，Phantom 用罗马数字。奔驰、宝马、奥迪省略四驱标识。指南、目录清单、补充文件和命名历史都不发送 API。

只有「记住名称」和归档确认产生学习样本。精确车型可直接记忆；同车系至少两个不同配置一致才推广车系规则，品牌规则至少三个车系支持。默认推广需确认，自动模式达到门槛后应用，手动模式只接受显式记忆。规则可审查、预览、批准、编辑、停用、删除和导出，不推广型号数字等识别事实。

分类目录重新连接后，本轮继续完成命名整理：程序内置基础指南，用户确认的本地习惯作为可审查覆盖层；补充要求优先于历史多数格式。即使归档目录离线，仍可生成名称；目录补全只列出现存分类。未知字段不猜测，来源不可靠的条目不跨车系推广。核对表、覆盖清单和冲突说明用于检查规则。

## 数据与维护

每版数据位于根目录 Data：数据库、缓存、命名记录、独立照片副本、备份、WebView2 数据和崩溃报告。根启动器与 Program 内 EXE 解析相同位置，不可写时明确报错，不回退 C 盘。同工作区派生版本不可同时运行。

首次导入使用一致性备份和校验，更新内部缓存路径，保留原照片路径及旧数据，不递归复制历史备份。Key 以当前 Windows 用户 DPAPI 加密，换用户或换机须重新输入。

清缓存只处理可重建内容，保留缺原图时必要的预览。崩溃报告只保存有限近期行为，不含照片、Key 或输入全文，不自动上传；正常退出清理会话检查点。备份前关闭应用，再复制整个 Data。旧版本及其 Data 不自动删除。

dotnet run --project ..\CarArchive.Tests\CarArchive.Tests.csproj
dotnet run --project ..\CarArchive.PhotoTests\CarArchive.PhotoTests.csproj
