# 重复文件检查

运行 `DuplicateChecker.exe` 可独立检查文件。工具无需 CarArchive、数据库或 API Key。

1. 选择目标目录和比较目录。比较目录总是扫描子文件夹，目标目录可切换是否扫描子文件夹。输出目录留空时使用目标目录。
2. 点击「检查并移动」，工具会按文件内容检查，然后自动移入新结果目录下的 `已有` 和 `暂无`，保留子目录结构。待核查文件留在原位。
3. 进度条显示当前阶段，完成后显示分类数量。结果目录保留移动清单及 `.operations` 下的日志。重新启动后可点「载入移动记录」，选择该结果目录后继续移动或还原。

已生成的结果目录会从后续目标扫描中跳过。比较目录只读；同内容异名可识别，重新编码或修改元数据的文件需要单独检查。操作文件前请先完成 CarArchive 中正在使用这些文件的分组。

开发入口为 `App/DuplicateChecker.csproj`（.NET WPF），扫描与文件操作位于 `Core`。在 Windows 上执行 `Publish.ps1` 可独立打包。
